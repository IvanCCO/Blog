- `animation/`: 12 skills baseadas no curso **Animations on the Web**, do Emil
  Kowalski, incluindo implementação, performance e acessibilidade.

- `vercel-react-best-practices/`: performance de React e Next.js.

Este projeto usa React 18. As orientações específicas de React 19 não se aplicam.
As cópias locais incluem os arquivos de referência e as regras dos pacotes originais.
